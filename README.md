# Mídia pública do @geovane.gestordeperformance

Imagens dos posts do Instagram, em JPG, num link público: a API do Instagram baixa cada imagem daqui na hora de publicar.

Tudo aqui é público. Só entram imagens que já vão ser publicadas; nada de print de cliente sem borrar, rascunho ou dado privado.

Uma pasta por post, com o mesmo nome da pasta em `conteudo/` do repositório de rascunhos: `relatorio-aberto-001/slide-1.jpg` a `slide-7.jpg`.
